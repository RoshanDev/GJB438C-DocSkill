# Word 格式与前三页实现

## 统一前三页

母版路径：

```text
templates/front-matter/standard-front-matter.docx
```

母版源自用户提供的前置页版式文件。来源文件的前三页分别包含首页、签字页和变更履历；母版化时将其与后续目录、正文分离，并修正兼容渲染器下的分页漂移。归一化母版保留原表格、文本框、字体、位置和留白，只截断后续内容并稳定分页。

生成器不依赖长占位符，因为长占位符会改变 Word 自动换行和分页。字段通过严格锚点及表格坐标写入：

- 档案编号；
- 密级、项目代号、文件编号、阶段标记、文件版本；
- 软件名称和文档名称；
- 编制单位与中文日期；
- 编制、审核、标审、会签、批准；
- 变更履历数据行。

模板锚点、顶层表格数、表格行列或字段命中数发生漂移时直接报错。

## 正文样式

生成器不修改母版的 `Normal` 样式。前三页签字行依赖原模板样式和段落度量，全局修改 `Normal` 会导致签字页被挤成两页。所有新增内容使用独立样式：

| 样式 | 字体与段落 |
|---|---|
| `GJB 目录标题` | 16 pt 宋体，1.5 倍，居中 |
| `TOC 1`～`TOC 9` | 12 pt 宋体，1.5 倍，两端对齐，保留层级缩进 |
| `GJB 标题 1`～`GJB 标题 9` | 12 pt 黑体，1.5 倍 |
| `GJB 正文` | 12 pt 宋体，西文 Times New Roman，1.5 倍，两端对齐，首行两字符 |
| `GJB 正文无缩进` | 同正文但无首行缩进 |
| `GJB 图表题` | 10.5 pt 黑体，单倍，居中 |
| `GJB 表内文字` | 10.5 pt 宋体，单倍，居中 |
| `GJB 代码` | 10.5 pt，中文宋体、西文 Times New Roman，单倍 |

## 节、目录和页码

生成结果至少含三个节：

1. 统一前三页，无可见页码；
2. 目录，罗马页码；
3. 正文，阿拉伯页码重新从 1 开始。

目录使用原生 `TOC` 域，并用 `GJB_BODY` 书签限定为正文范围，避免把首页、签字页和变更履历采入目录。目录/正文页脚均使用原生 `PAGE` 域。

`refresh-toc` 不接受 LibreOffice 保存后的整份 DOCX，因为 LibreOffice 可能折叠节、重写样式或移除 `updateFields`。实现会创建临时副本让 LibreOffice计算目录，然后只把 TOC 字段的缓存结果移植回原文档。
